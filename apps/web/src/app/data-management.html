FULL GARMIN CONNECT ARCHIVE

Rebuild the activity library

The complete export can rebuild activity summaries and link their FIT files. This restore uses a separate database so you can inspect it before switching away from the current one.

  1. Catalog the FIT archive once: dotnet run --project tools/Garmin.Import -- catalog-fit "/path/to/DI_CONNECT/DI-Connect-Uploaded-Files" --output "/tmp/garmin-fit-catalog.csv".
  2. Build a new database: dotnet run --project tools/Garmin.Import -- import-garmin-export "/path/to/DI_CONNECT" --catalog "/tmp/garmin-fit-catalog.csv" --database "/tmp/activities.rebuilt.db" --supplement-database "/path/to/current/activities.db".
  3. Review the reported import counts, then point GARMIN_DB_PATH at the rebuilt database and import wellness history from this page.

The rebuilt activity database does not include wellness tables’ records until the wellness import is run against that database. Keep the original database until the rebuilt one is checked.
